# AI-Application - LingoBaby

인공지능응용 팀플 레포입니다.

## 👏🏻 프로젝트 개요
아동 음성 입력을 기반으로 발달 수준을 분석하고, 
부모에게 맞춤형 언어 교육 가이드, 
자폐 위험 신호 감지를 종합적으로 제공하는 AI 시스템

## 🌟 프로젝트 목표
- 단순 문법 교정이 아님
    - 아동 발화의 오류만을 지적하는 방식이 아니라 발달 단계를 고려해 평가
- 구체적이고 실천 가능한 조언 제공
    - 아이의 현재 발화 특성을 기반으로 구체적인 언어 지도 방향 제공
- 조기 개입을 위한 신호 감지 기능 포함
    - 발화 내용과 발화 스타일을 함께 분석해 자폐 스펙트럼 위험 신호가 감지되면 부모에게 전문 상담을 권장
